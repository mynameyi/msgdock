# MsgDock 0.1.0 MVP

本版将系统设计与首页原型实现为可运行的管理控制台和异步推送服务。它面向单工作空间、自托管、少量管理人员起步的场景。

## 已实现

- React 19、Vite、Ant Design 控制台，按 Feature-based 分页，路由懒加载，TanStack Query 维护服务端状态。
- 首次管理员初始化、Argon2id 密码摘要、服务端会话、CSRF、登录限速、修改密码与操作审计。首版管理员统一为 Owner。
- 应用、默认 Bearer API Key 鉴权、显式非鉴权发送、目标授权、应用限额、密钥生成和重叠轮换 / 撤销。
- 企业微信群 Webhook、飞书群 Webhook 与可选 HMAC 签名、钉钉企业机器人 OpenAPI 文本适配。渠道凭证使用 AES-256-GCM 加密。
- 注册目标、静态主题路由、受控文本模板、不可变模板版本；受理时固定目标和消息快照。
- PostgreSQL 事务 Outbox、并发幂等、Redis / BullMQ、实例令牌桶、租约与条件领取、期限、最多六次受控重试。
- 目标级投递、尝试记录、平台接受与 unknown 区分；取消、关联重发、核实结果与审计。
- OpenAPI JSON、由契约生成的前端请求类型和 openapi-fetch 调用封装。响应展示模型在各前端功能中定义。
- 一个最终 Docker 镜像，一个容器运行 API、Worker、PostgreSQL 和 Redis；持久化卷、启动迁移、健康检查、有序退出与数据恢复。

## 工程组织

```text
apps/console/src/features/   # overview、channels、applications、templates、routing、deliveries、identity、system
apps/api/src/http/          # HTTP Controller、DTO、Guard
apps/worker/src/            # 独立 Worker 启动装配
packages/server/src/        # identity、configuration、notifications、deliveries 与基础设施
packages/channels/src/      # 平台协议、发送与错误归一化
packages/contracts/src/     # 内部稳定接口
packages/database/prisma/  # 模型与迁移
packages/api-client/src/    # OpenAPI 请求契约与客户端
deploy/                    # 单容器入口、Supervisor 与健康检查
```

简单的应用、渠道、主题和模板配置先集中在 configuration 模块；可靠受理与投递保留独立业务模块。Worker 直接使用 BullMQ 的 Queue / Worker API，由 NestJS 服务负责生命周期。前后端代码分离，构建后由 Fastify 同域提供静态控制台与 API。

## 验证范围

| 范围 | 验证内容 |
| --- | --- |
| 单元测试 | 官方地址约束、飞书签名、平台业务错误、429 与超时分类、状态决策、重试上限、模板与规范化摘要 |
| API 集成 | 初始化、登录、CSRF、默认鉴权、匿名模式、不降级、跨应用隔离、并发幂等、密钥撤销、模板快照、失败、未知结果和重试 |
| 容器 | 空卷初始化、迁移、四个进程与健康、重启后会话 / 密钥 / 凭证恢复、发送恢复 |
| 队列故障 | 清空独立测试 Redis 后恢复数据库待执行计划，不产生额外发送尝试；取消的计划不发送 |
| 浏览器 | 登录、各功能路由、渠道与应用表单、趋势和状态展示；窄屏表格在自身区域滚动 |

模拟平台测试不替代真实企业环境联调。本版未使用用户的真实 IM 凭证、未向真实群发送验证消息；平台权限、关键词规则、实际配额与机器人加入群等需在具体实例中验证。

## 明确的后续范围

多管理员与分角色授权、自动数据保留和脱敏清理、媒体、Markdown / 卡片、平台事件 Inbox 与交互回调、微信各开放产品、智能机器人长连接、严格顺序、多维平台配额及高可用部署后续增加。

MVP 默认一个活动实例。公开 API 的受理暂依赖 Redis 限额服务；Redis 不可用时拒绝新受理。现有固定租约与请求超时适用于已实现的短文本渠道，未实现通用长任务续租运行时。没有端到端恰好一次或用户送达 / 已读保证。

当前没有容量或 SLA 实测承诺，日志与审计不自动清理。应用镜像保留数据库迁移工具和部分共享依赖，后续可继续收敛镜像体积。默认对外仅提供已有网关后的 HTTP 服务；HTTPS 由部署环境终结。
